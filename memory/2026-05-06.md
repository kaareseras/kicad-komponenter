# 2026-05-06

- In Discord #kicad-design, user asked for a chip/circuit with I2C and at least 3 PWM outputs.
- Recommended PCA9685 as the practical default: I2C-controlled, 16 PWM outputs, widely used and suitable for LED dimming or driving MOSFET gates, with the explicit note that it provides logic/PWM outputs rather than power outputs and may need external MOSFET/transistor stages for real loads.
