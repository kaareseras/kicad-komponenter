# 2026-04-20

- User is designing KiCad-based power/measurement hardware and prefers Danish replies in Discord.
- Current architecture direction: ADS131M08IPBS(R) on a hot/load board with isolated interface to an ESP32-S3 low-voltage board; isolation should be handled with digital isolator(s) plus isolated DC/DC, not by tying grounds together.
- Recommended ADS131M08 isolated signal set discussed: SCLK, DIN, CS, RESET from MCU to ADC and DOUT, DRDY from ADC to MCU (6 total if done properly).
- For digital isolation, a 6-channel isolator class like TI ISO7762 was recommended over a 4-channel part when including DRDY and RESET.
- For hot-side power from a 12V cold side, recommended approach was isolated DC/DC plus local regulation, preferably 12V -> 5V on cold side, then isolated 5V->5V converter and hot-side 3.3V LDO for ADC/isolator supply.
- User asked for a concrete isolated supply recommendation for powering only the ADC and digital isolator hot side; a B0505S-1W class isolated converter was suggested if a 5V rail exists before the isolation barrier.
- User asked about connectors between power board and ESP board carrying 12V, GND, and signals; Molex Micro-Fit 3.0 was recommended as the more robust choice, with JST XH as a cheaper/simpler option.
- User also discussed cheap I/O expanders; PCF8574MS/TR was considered acceptable for indirect relay drive and reading physical inputs, with the caveat that PCF8574 uses quasi-bidirectional I/O and is a bit quirky compared with MCP23017.
- Arduino-library guidance given: PCF8574 has usable Arduino libraries, and an example sketch was provided for relay control and physical input reading.
- User asked about legal/safety considerations for a 3D-printed enclosure in ABS or PETG for the project.
- Guidance given: for private prototype use there are fewer formal legal requirements, but real safety concerns remain; for anything sold/distributed or mains-connected, issues include CE/product safety, flammability, touch safety, cable strain relief, thermal behavior, and ensuring the enclosure does not compromise hot/cold isolation.
